# 🍔 Sistema de Gestão para Microempreendedor

Sistema web desenvolvido para auxiliar um microempreendedor do ramo alimentício na administração diária do negócio. O objetivo do projeto é centralizar informações, automatizar processos e reduzir o tempo gasto com tarefas manuais.

## 📋 Sobre o Projeto

Este sistema foi criado para facilitar o gerenciamento de pedidos realizados por diferentes plataformas de delivery, além de controlar pagamentos de motoboys e gerar o fechamento diário da empresa.

A aplicação foi desenvolvida com foco em simplicidade, desempenho e facilidade de utilização.

## ✨ Funcionalidades

- 📦 Cadastro e gerenciamento de pedidos
- 📊 Controle de pedidos por plataforma
  - iFood
  - Anota AI
  - 99Food
- 💰 Controle de pagamentos dos motoboys
- 📅 Fechamento diário
- 📈 Relatórios administrativos
- 📂 Importação de dados via planilhas Excel
- 📱 Integração com API do WhatsApp
- 🔎 Consulta e filtragem de pedidos
- 👥 Controle de usuários

## 🚀 Como executar

### Pré-requisitos

- PHP 8+
- MySQL
- Servidor Apache (XAMPP, WAMP ou Laragon)

### Instalação

1. Clone o repositório

```bash
git clone [https://github.com/l-pEtrick-l/restaurant-case-study]
```

2. Importe o banco de dados.

3. Configure o arquivo de conexão com o banco.

4. Execute o projeto em um servidor Apache.
